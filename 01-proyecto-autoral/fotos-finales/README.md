```

02_titulo-corto.jpg
...
```

El número al inicio define el orden en el PDF.

## Requisitos

- Coherencia conceptual, estética y técnica entre las imágenes
- Resolución alta (mínimo 2000px en el lado largo recomendado)
- Formato JPG o PNG
