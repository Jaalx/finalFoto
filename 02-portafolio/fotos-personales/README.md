# Fotos personales (opcional)

Sección **opcional**. Fotos tuyas que no son de los cortes 1 ni 2 pero que quieres mostrar.

## Cuándo incluirla

- Si tienes trabajo personal que complementa tu mirada
- Si quieres mostrar otros registros (viajes, documentales personales, ensayos)
- Si quieres dar más volumen al portafolio

## Cuándo NO incluirla

- Si las fotos no están al nivel del resto
- Si rompen la coherencia del portafolio
- Si las dejas solo "por rellenar"
