# PDF final

Aquí va el **PDF único** que se entrega por WhatsApp.

## Orden obligatorio del documento

1. **Proyecto Autoral**
   - Portada del proyecto (opcional pero recomendada)
   - Statement (`../01-proyecto-autoral/statement.md`)
   - 10-12 fotografías (`../01-proyecto-autoral/fotos-finales/`)

2. **Página en blanco** (cierre del proyecto autoral)

3. **Portafolio**
   - Portada del portafolio (`../02-portafolio/portada/`)
   - [Opción A: Autorretrato + autobiografía aquí]
   - Trabajos del primer corte (`../02-portafolio/primer-corte/`)
   - Trabajos del segundo corte (`../02-portafolio/segundo-corte/`)
   - Fotos personales (opcional, `../02-portafolio/fotos-personales/`)
   - [Opción B: Autorretrato + autobiografía al final]

## Recordatorios

- No titular las secciones como "capítulo 1 / capítulo 2"
- Incluir **enlace funcional** al portafolio web (GitHub Pages) dentro del PDF
- Cada autor entrega **su propio** PDF (incluso si el proyecto autoral fue grupal)
- En el PDF grupal cada integrante debe tener **su** autobiografía

## Nombre del archivo

Sugerencia: `Apellido_Nombre_ProyectoFinal.pdf`

## Herramientas para compilar el PDF

- Adobe InDesign
- Canva
- Affinity Publisher
- LaTeX (si te animas)
- Word / Google Docs (mínimo viable)
