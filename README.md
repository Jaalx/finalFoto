# Proyecto Final — Tercer Corte

Entrega: **un solo PDF** con dos secciones + **portafolio web** (GitHub Pages).

## Estructura

```
proyecto foto/
├── 01-proyecto-autoral/      → 10-12 fotos + statement
│   ├── fotos-finales/        → fotos seleccionadas para entrega
│   ├── seleccion-trabajo/    → fotos en proceso de selección
│   ├── referencias/          → referencias visuales / inspiración
│   └── statement.md          → texto del autor (plantilla incluida)
│
├── 02-portafolio/            → trabajos cortes 1 y 2 + autobiografía
│   ├── portada/              → portada del portafolio
│   ├── primer-corte/         → trabajos primer corte
│   ├── segundo-corte/        → trabajos segundo corte
│   ├── fotos-personales/     → opcional
│   ├── autorretrato/         → foto del autor (importante)
│   └── autobiografia.md      → texto breve (plantilla incluida)
│
├── 03-pdf-final/             → aquí se compila el PDF final
│
└── 04-portafolio-web/        → sitio GitHub Pages
    ├── index.html
    └── assets/
```

## Orden del PDF final

1. Proyecto Autoral (fotos + statement)
2. Página en blanco (cierre)
3. Portada del portafolio
4. Portafolio (cortes 1 y 2 + opcional fotos personales)
5. Autobiografía + autorretrato

## Formato

- Un solo PDF
- Dos secciones sin titularlas "capítulo 1 / 2"
- Enlace al portafolio web funcionando dentro del PDF
- Entrega por WhatsApp

## Si el proyecto autoral es grupal

- Las fotos pueden ser conjuntas
- Cada integrante envía su propio PDF
- Cada PDF lleva la autobiografía del autor que entrega
